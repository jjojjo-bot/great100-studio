# Great100 Studio

‘한국을 빛낸 100인’ 영상 제작을 위한 React + TypeScript 스튜디오입니다. 웹앱으로 사용할 수 있고, Tauri 데스크톱 앱도 포함합니다.

## 로컬 웹 실행

```bash
npm install
npm run dev
```

웹앱에서 접근 코드를 비워두면 mock 이미지로 전체 흐름을 사용할 수 있습니다. 프로젝트와 업로드한 파일은 이 브라우저의 IndexedDB에 저장됩니다. 장면별 자막과 표시 시간을 수정하고 모든 장면의 이미지 또는 동영상을 선택한 뒤 완료 단계에서 **MP4 만들기**를 누르세요. 브라우저가 1280×720 H.264 MP4를 직접 만들며, 장면별 내레이션과 배경음악을 추가할 수도 있습니다. 최신 Chrome/Edge에서 사용하세요.

MP4가 완성된 뒤 ZIP을 내려받으면 `projects/<회차_인물>/05_exports/<회차_인물>.mp4`와 원본 자료를 함께 보관합니다. 브라우저 데이터를 지우거나 다른 기기로 옮기면 저장 내용이 자동으로 따라가지 않으므로 ZIP을 보관하세요. 영상 제작은 브라우저의 인코더와 메모리를 사용하며 영상 길이는 최대 15분입니다.

API 결제 없이 ChatGPT Plus에서 만든 이미지를 사용하려면 각 기준 이미지·Scene·썸네일 단계에서 **이미지 업로드**를 누르세요. PNG/JPEG/WebP 파일을 한 번에 최대 6장, 각 12MB까지 추가할 수 있습니다. 마지막으로 업로드한 이미지가 자동 선택되며 다른 후보를 클릭해 바꿀 수 있습니다. 업로드 이미지도 브라우저에 저장되고 ZIP의 해당 폴더에 포함됩니다. 브라우저 저장 용량에는 한계가 있으므로 작업을 마치면 ZIP을 내려받으세요.

Scene 단계에서는 **MP4 업로드**로 이미지 대신 10초 이하·50MB 이하의 동영상 한 편을 메인 화면으로 선택할 수 있습니다. 장면 길이보다 짧으면 마지막 프레임을 유지하고 길면 장면 끝에서 자릅니다. 업로드 MP4의 원본 소리는 출력하지 않으며 앱의 내레이션·배경음악만 사용합니다. 기준 이미지, 보조 이미지, 썸네일은 계속 이미지 전용입니다. ZIP에는 선택한 동영상 원본도 `03_images/sceneXX/selected.mp4`로 들어갑니다.

각 Scene에는 편집 가능한 장면 내용과 **복사용 전체 이미지 프롬프트**가 따로 보입니다. 전체 프롬프트는 현재 인물 외형 기준, 기본 그림책 스타일, 제작안의 추가 이미지 조건을 항상 합쳐 보여 줍니다. **전체 프롬프트 복사**를 눌러 ChatGPT 이미지 생성에 그대로 붙여넣을 수 있고, 앱의 후보 생성에도 같은 문장이 사용됩니다. ZIP에는 장면별 `03_images/sceneXX/image_prompt.txt`와 `project_data.json`의 `full_prompt`가 포함됩니다.

Work 제작안은 `Scene 1`·`장면 1` 형식, 열 이름과 순서가 조금 다른 마크다운 표, JSON 형식을 읽습니다. 장면별 시간·프롬프트·내레이션 자막을 가능한 범위에서 자동으로 가져옵니다. 자동 인식에 실패하거나 내용이 틀리면 **파싱 확인**에서 장면을 직접 추가·수정할 수 있습니다. 이미 만든 프로젝트는 **파싱 확인 → 원문 다시 분석**으로 다시 읽을 수 있습니다.

마음에 들지 않는 프로젝트는 대시보드의 프로젝트 카드에서 **삭제**를 누른 뒤 확인할 수 있습니다. 웹에서는 해당 브라우저의 프로젝트·후보 이미지·완성 MP4가 함께 영구 삭제됩니다. 데스크톱에서는 실제 프로젝트 폴더를 `projects/.trash/`로 옮겨 앱 목록에서 제외하므로 수동 복구가 가능합니다. 두 경우 모두 다른 프로젝트에는 영향을 주지 않습니다.

## Vercel 배포

저장소 루트에서 `vercel`을 실행하면 Vite 웹앱과 `api/generate.ts` 함수가 함께 배포됩니다. 실제 OpenAI 이미지 생성을 사용할 때만 Vercel 환경 변수 두 개를 설정합니다.

- `OPENAI_API_KEY`: 서버에서만 읽는 OpenAI API 키
- `GREAT100_ACCESS_KEY`: 개인 사용을 위한 별도 접근 코드. 웹앱의 입력칸에 이 코드를 입력합니다.

두 값 중 하나라도 없으면 서버의 실제 이미지 생성은 비활성화됩니다. 접근 코드는 OpenAI API 키가 아닙니다. 이 개인 사용 방식은 계정별 분리나 공유 프로젝트를 제공하지 않습니다. 다른 사용자에게 공개하기 전에는 사용자 인증, 사용량 제한, 중앙 저장소가 필요합니다.

웹에서 실제 생성 요청을 로컬로 시험하려면 `vercel dev`를 사용합니다. 일반 `npm run dev`는 프런트엔드와 mock mode를 실행합니다.

## 데스크톱 실행

Rust와 macOS 개발 도구가 설치된 환경에서는 다음을 실행합니다.

```bash
npm run tauri dev
```

macOS에서 Xcode 전체 설치의 라이선스가 미동의 상태여도 Command Line Tools가 설치되어 있다면 `DEVELOPER_DIR=/Library/Developer/CommandLineTools`를 명령 앞에 지정할 수 있습니다. 데스크톱 앱은 프로젝트 루트 아래 실제 `projects/` 폴더를 생성합니다. `OPENAI_API_KEY`가 없으면 mock 이미지가 저장됩니다.

## 프로젝트 구성

`projects/<회차_인물>/`에는 `project_data.json`과 다음 하위 폴더가 들어갑니다.

- `01_source`
- `02_character`
- `03_images/sceneXX`
- `04_thumbnail`
- `05_exports`
- `06_logs`

웹 ZIP에는 완성 MP4, 원문, 프로젝트 데이터, 생성 이미지, 최종 선택 이미지, 프롬프트 이력이 들어갑니다. 데스크톱 앱은 완성 MP4를 프로젝트의 `05_exports` 폴더에도 저장합니다.
